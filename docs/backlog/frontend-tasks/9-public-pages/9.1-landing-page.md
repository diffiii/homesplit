# 9.1 Build the landing page

**Epic:** [9 Public pages](9.0-epic.md) · **Depends on:** [2.1](../2-auth-account/2.1-sign-up-sign-in.md)

**Goal:** A short public page explains HomeSplit and leads to sign-up.

**Scope:** A statically rendered landing page with metadata for search engines and link previews.

**Acceptance criteria:**

- [ ] The page presents expenses, settling up, chores, and shopping, with calls to sign up and sign in.
- [ ] It's statically rendered and passes the definition of done.
- [ ] Title, description, and Open Graph images are set for the landing page and default for the rest of the app.
