# 5.1.1 Manage expense categories

**Epic:** [5.1 Ledger](5.1.0-epic.md) · **Depends on:** [3.2](../../3-households/3.2-household-shell.md), [#35](https://github.com/diffiii/homesplit/issues/35), [#37](https://github.com/diffiii/homesplit/issues/37)

**Goal:** Admins keep a short list of categories with emoji icons that members pick from.

**Scope:** A categories section in household settings and a category picker for the expense form.

**Acceptance criteria:**

- [ ] Every member sees the categories. Admins and owners create, rename, and delete them, and set or clear an emoji icon with an emoji picker.
- [ ] Deleting a category that expenses use shows 409 `CATEGORY_IN_USE` as an explanation.
- [ ] A reusable category picker shows icon and name, with an empty choice for no category.
