# 5.1.4 Build the expense form in simple mode

**Epic:** [5.1 Ledger](5.1.0-epic.md) · **Depends on:** [5.1.1](5.1.1-categories.md), [5.1.3](5.1.3-expense-list-detail.md), [1.3](../../1-foundation/1.3-shared-allocation-engine.md), [#37](https://github.com/diffiii/homesplit/issues/37)

**Goal:** The common case, "I paid, split equally", takes one screen on a phone.

**Scope:** A create form with name, amount, currency, date, category, "paid by me", and an equal split among selected members, with a live split preview.

**Acceptance criteria:**

- [ ] Defaults: today in the user's time zone, the last currency used in this household on the device (falling back to PLN), the user as the only payer, and every current member as a participant.
- [ ] Participants can be toggled, and a preview shows each person's share computed with the shared allocation engine, updating as the user types.
- [ ] The form validates with `CreateExpenseRequest` before sending, and server errors, including 400 `INVALID_REFERENCE` after a member leaves, appear on the right fields.
- [ ] After saving, the new expense appears in the list and the balances are refetched.
