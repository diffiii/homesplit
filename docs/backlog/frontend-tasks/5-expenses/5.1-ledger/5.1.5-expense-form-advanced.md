# 5.1.5 Add the advanced expense form

**Epic:** [5.1 Ledger](5.1.0-epic.md) · **Depends on:** [5.1.4](5.1.4-expense-form-simple.md)

**Goal:** Any expense the API accepts can be entered through the form.

**Scope:** An "advanced" section of the 5.1.4 form for multiple payers and the percentage, shares, exact, and adjustment methods.

**Acceptance criteria:**

- [ ] Several payers can be added with amounts, and the form shows how much of the total is still unassigned.
- [ ] Each method has its own inputs (percentages, shares, exact amounts, signed adjustments) and a running check: percentages left to 100%, exact amounts left to the total, and negative shares from adjustments.
- [ ] Switching methods keeps the selected participants. Switching back to simple mode is offered only when the expense fits it.
- [ ] The preview uses the shared engine for every method, and issues from `CreateExpenseRequest` appear on the participant or payer row they belong to.
