# 5.1.3 Build the expense list and detail

**Epic:** [5.1 Ledger](5.1.0-epic.md) · **Depends on:** [3.2](../../3-households/3.2-household-shell.md), [5.1.2](5.1.2-expense-list-filters.md), [#37](https://github.com/diffiii/homesplit/issues/37)

**Goal:** Members scan recent expenses and see exactly how any one of them was split.

**Scope:** The expense list with filters and the expense detail page.

**Acceptance criteria:**

- [ ] The list loads pages as the user scrolls, grouped by date, showing name, category, total, who paid, and the user's own share.
- [ ] Filters for category, person, and date range use 5.1.2, are kept in the URL, and can be cleared at once.
- [ ] The detail page shows payers and amounts, the allocation method with its inputs, each split, author, category, date, and description, with departed members marked.
- [ ] Amounts in different currencies are never added together.
