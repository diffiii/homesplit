# 5.1.2 Add expense list filters

**Labels:** `backend`, `frontend` · **Epic:** [5.1 Ledger](5.1.0-epic.md) · **Depends on:** [#37](https://github.com/diffiii/homesplit/issues/37)

**Goal:** Members find expenses by category, person, or period without paging through the whole history.

**Scope:** Optional filters on `GET /expenses`: `categoryId`, `userId`, `from`, and `to`, with the contract, endpoint map, route doc, and indexes.

**Acceptance criteria:**

- [ ] `categoryId` matches expenses in that category. A separate value or parameter for uncategorized expenses is decided and documented.
- [ ] `userId` matches expenses where the user is a payer or an allocation participant, and accepts any household party, departed members included.
- [ ] `from` and `to` are inclusive `IsoDate` bounds on `expenseDate`, and `from` after `to` answers 400 `VALIDATION_ERROR`.
- [ ] Filters combine with AND, keep the contracted order and pagination, and `totalItems` counts filtered results. IDs from another household match nothing, without an error.
- [ ] Indexes support the filters with the list order, and tests cover each filter, combinations, departed members, and another household's IDs.
