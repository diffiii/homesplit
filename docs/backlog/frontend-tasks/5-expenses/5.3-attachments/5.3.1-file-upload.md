# 5.3.1 Build the file upload component

**Epic:** [5.3 Attachments](5.3.0-epic.md) · **Depends on:** [1.7](../../1-foundation/1.7-app-shell-ui-kit.md), [#44](https://github.com/diffiii/homesplit/issues/44)

**Goal:** One upload component handles camera photos and files for expenses and receipts.

**Scope:** A component on the [#44](https://github.com/diffiii/homesplit/issues/44) upload endpoint, with checks before upload, progress, and previews.

**Acceptance criteria:**

- [ ] Users take a photo with the camera or pick files. Types and the size limit from [#44](https://github.com/diffiii/homesplit/issues/44) are checked before uploading, with a clear message.
- [ ] Uploads show progress and can be cancelled and retried.
- [ ] Images are previewed where the browser can display them. HEIC and PDF files show a file icon where it can't.

**References:** [#44](https://github.com/diffiii/homesplit/issues/44)
