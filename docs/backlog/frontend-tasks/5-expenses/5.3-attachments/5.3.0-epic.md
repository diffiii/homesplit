# Sub-epic 5.3: Attachments

**Parent:** [Epic 5: Expenses](../5.0-epic.md)

**Goal:** Members attach receipts and invoices to expenses from their phone camera or files and view them later, and users upload an avatar, using the same file storage.

**Tasks:**

- [5.3.1 Build the file upload component](5.3.1-file-upload.md)
- [5.3.2 Attach files to expenses](5.3.2-expense-attachments.md)
- [5.3.3 Add avatar upload](5.3.3-avatar-upload.md)
- [5.3.4 Upload and remove avatars](5.3.4-avatar-ui.md)

**Sub-epic done when:**

- [ ] A member photographs a receipt, attaches it while creating an expense, and another member opens it from the expense.
- [ ] A user uploads an avatar, and other members see it on expenses and member lists; removing it falls back to initials.
