# 5.3.3 Add avatar upload

**Labels:** `backend`, `frontend` · **Epic:** [5.3 Attachments](5.3.0-epic.md) · **Depends on:** [#30](https://github.com/diffiii/homesplit/issues/30), [#44](https://github.com/diffiii/homesplit/issues/44)

**Goal:** Users upload a profile picture, and every place that shows them gets a stable image URL.

**Scope:** `PUT /api/me/avatar` and `DELETE /api/me/avatar` on the [#44](https://github.com/diffiii/homesplit/issues/44) storage adapter, with the contract and endpoint map entries.

**Acceptance criteria:**

- [ ] Uploads accept JPEG, PNG, WebP, and HEIC up to a configured size, checked from the file content. The image is re-encoded to a square WebP of a fixed size, so it carries no metadata.
- [ ] The image is stored under a public-read `avatars/` prefix with a random key per upload, and `user.image` is set to its URL. Replacing or deleting the avatar deletes the previous object.
- [ ] The response is the user's `UserSummary`. `DELETE` sets `imageUrl` to `null` and answers 204.
- [ ] `PATCH /api/me` from [#30](https://github.com/diffiii/homesplit/issues/30) only accepts `imageUrl: null` or a URL on the avatar host, so users can't point their avatar at arbitrary URLs.
- [ ] Tests cover each type, an oversized file, a disguised file, replacement, and deletion.
