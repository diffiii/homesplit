# 5.3.2 Attach files to expenses

**Epic:** [5.3 Attachments](5.3.0-epic.md) · **Depends on:** [5.3.1](5.3.1-file-upload.md), [5.1.6](../5.1-ledger/5.1.6-expense-edit-delete.md), [#45](https://github.com/diffiii/homesplit/issues/45)

**Goal:** Files belong to the expense they document.

**Scope:** Attaching in the expense form, listing on the detail page, viewing through download links, and detaching.

**Acceptance criteria:**

- [ ] Files can be attached when creating or editing an expense, and are listed with type and size on its detail page.
- [ ] Opening a file requests a fresh download link, with images shown in a viewer and other files downloaded.
- [ ] Detaching follows the rights [#45](https://github.com/diffiii/homesplit/issues/45) sets, and attaching and detaching are unavailable while the expenses module is disabled.
- [ ] Deleting an expense explains what happens to its files, as [#45](https://github.com/diffiii/homesplit/issues/45) decides.

**References:** [#45](https://github.com/diffiii/homesplit/issues/45)
