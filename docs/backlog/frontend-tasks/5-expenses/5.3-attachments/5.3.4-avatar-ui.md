# 5.3.4 Upload and remove avatars

**Epic:** [5.3 Attachments](5.3.0-epic.md) · **Depends on:** [5.3.1](5.3.1-file-upload.md), [5.3.3](5.3.3-avatar-upload.md), [2.5](../../2-auth-account/2.5-profile-account.md)

**Goal:** Users put a face to their name, and everyone else sees it wherever that user appears.

**Scope:** An avatar section on the 2.5 account page using the 5.3.3 endpoints and the 5.3.1 upload component.

**Acceptance criteria:**

- [ ] The avatar can be taken with the camera or picked from files, cropped to a square, previewed, uploaded with progress, and removed. Initials are shown without one.
- [ ] After a change, the session and every cached `UserSummary` of the user are refreshed, so the new avatar appears without reloading.

**References:** [5.3.3](5.3.3-avatar-upload.md), [user contracts](../../../../../packages/contracts/src/features/users/index.ts)
