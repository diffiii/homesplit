# Sub-epic 5.2: Settlements

**Parent:** [Epic 5: Expenses](../5.0-epic.md)

**Goal:** Members see who owes whom in each currency, record payments in a tap from the suggestions, and confirm payments they received.

**Tasks:**

- [5.2.1 Show balances](5.2.1-balances.md)
- [5.2.2 Build settling up](5.2.2-settle-up.md)
- [5.2.3 Show payment history and confirmations](5.2.3-payment-history.md)

**Sub-epic done when:**

- [ ] Recording every suggested payment and confirming the pending ones brings each currency's balances to zero in the UI.
- [ ] A departed member's debt can be settled or written off by an admin, as the decision record describes.
