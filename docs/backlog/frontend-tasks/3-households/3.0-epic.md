# Epic 3: Households

**Backlog:** [Frontend backlog](../../frontend-backlog.md) · **Depends on:** [2 Auth and account](../2-auth-account/2.0-epic.md)

**Goal:** Members create and switch households, invite people, manage roles and modules, and leave or delete households under the decision-record rules. Every feature screen sits inside a household shell that knows the caller's role and the enabled modules.

**Tasks:**

- [3.1 List, create, and switch households](3.1-household-list-create.md)
- [3.2 Build the household shell](3.2-household-shell.md)
- [3.3 Manage members and roles](3.3-members-roles.md)
- [3.4 Send and answer invitations](3.4-invitations.md)
- [3.5 Leave and delete households](3.5-leave-delete.md)
- [3.6 Manage module settings](3.6-module-settings.md)
- [3.7 Build the household dashboard](3.7-dashboard.md)

**Epic done when:**

- [ ] A Playwright test creates a household, invites a new user who signs up from the email link and accepts, promotes them to admin, and disables and re-enables a module.
- [ ] Every household screen shows the right actions for `owner`, `admin`, and `member`, and departed members are shown consistently.
- [ ] Opening another household's URL, or one the user has left, shows a not-found page.
