# 3.1 List, create, and switch households

**Epic:** [3 Households](3.0-epic.md) · **Depends on:** [2.1](../2-auth-account/2.1-sign-up-sign-in.md), [#26](https://github.com/diffiii/homesplit/issues/26)

**Goal:** Users see their households, create new ones, and move between them quickly.

**Scope:** A household switcher, a create dialog, and the first-run screen, using Better Auth's `organization/list` and `organization/create`.

**Acceptance criteria:**

- [ ] Creating a household sends only `name` and a random UUID `slug`, then opens it.
- [ ] The switcher lists the user's households and is reachable from every household screen. The last opened household is remembered on the device.
- [ ] With no households, a first-run screen offers to create one or explains how to join through an invitation. Once [#59](https://github.com/diffiii/homesplit/issues/59) verifies emails, it also lists pending invitations to the user's email.
- [ ] Household names are validated as Better Auth and [#26](https://github.com/diffiii/homesplit/issues/26) expect.
