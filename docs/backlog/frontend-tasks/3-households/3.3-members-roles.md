# 3.3 Manage members and roles

**Epic:** [3 Households](3.0-epic.md) · **Depends on:** [3.2](3.2-household-shell.md), [#26](https://github.com/diffiii/homesplit/issues/26)

**Goal:** Members see who's in the household, and admins manage roles, removals, and the household name.

**Scope:** A members page and household settings using Better Auth's `get-full-organization`, `update-member-role`, `remove-member`, and `update`.

**Acceptance criteria:**

- [ ] Members are listed with name, avatar, email, role, and join date.
- [ ] Admins and owners can change roles and remove members under Better Auth's owner rules. Actions that would fail (removing yourself, demoting the last owner, an admin acting on an owner) aren't offered, and the server's answers, including 403 `CANNOT_REMOVE_SELF`, are explained.
- [ ] Removing a member explains that their history and any balance stay in the household.
- [ ] Admins and owners can rename the household. Only `name` is sent.
