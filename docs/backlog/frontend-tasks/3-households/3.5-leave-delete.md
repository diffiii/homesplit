# 3.5 Leave and delete households

**Epic:** [3 Households](3.0-epic.md) · **Depends on:** [3.3](3.3-members-roles.md), [#26](https://github.com/diffiii/homesplit/issues/26), [#40](https://github.com/diffiii/homesplit/issues/40)

**Goal:** Members can leave and owners can delete a household, and when the rules block them, they're told why and what to do.

**Scope:** Leave and delete actions with confirmations, using Better Auth's `leave` and `DELETE /api/households/:householdId`.

**Acceptance criteria:**

- [ ] Leaving asks for confirmation. A 409 `UNSETTLED_BALANCE` explains that the user must settle up first and links to settling up (5.2). The last owner is told to hand ownership on first.
- [ ] Deleting is offered only to owners and requires typing the household name. A 409 `HOUSEHOLD_HAS_UNSETTLED_BALANCES` links to balances.
- [ ] After leaving or deleting, the household disappears from the switcher and cached data, and the user goes to another household or the first-run screen.
