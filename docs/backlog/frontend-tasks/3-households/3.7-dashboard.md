# 3.7 Build the household dashboard

**Epic:** [3 Households](3.0-epic.md) · **Depends on:** [3.2](3.2-household-shell.md), [5.2.1](../5-expenses/5.2-settlements/5.2.1-balances.md), [6.2](../6-chores/6.2-chore-list-editing.md), [7.1](../7-shopping/7.1-shopping-list-editing.md)

**Goal:** Opening a household answers "what do I need to know right now?" at a glance.

**Scope:** The household home page with summary cards for each enabled module.

**Acceptance criteria:**

- [ ] Cards show the user's balance per currency (with a link to settle up), the user's open chores sorted by deadline, and the number of unpurchased shopping items. Each links to its module.
- [ ] Once 5.2.3 exists, a card lists payments waiting for the user's confirmation.
- [ ] Cards for disabled modules are hidden. Each card loads and fails independently.
- [ ] Each card uses one request: the chore card uses the 6.1 assignee filter, and the shopping card reads `totalItems` from a one-item page.
