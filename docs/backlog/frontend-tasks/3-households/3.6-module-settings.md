# 3.6 Manage module settings

**Epic:** [3 Households](3.0-epic.md) · **Depends on:** [3.2](3.2-household-shell.md), [#27](https://github.com/diffiii/homesplit/issues/27), [#40](https://github.com/diffiii/homesplit/issues/40)

**Goal:** Admins turn expenses, chores, and shopping on and off, knowing what that does.

**Scope:** A modules section in household settings using `GET` and `PATCH /features`.

**Acceptance criteria:**

- [ ] Every member sees which modules are on. Only admins and owners can change them, and each toggle explains that turning it off makes the module read-only and deletes nothing.
- [ ] A 409 `HOUSEHOLD_HAS_UNSETTLED_BALANCES` when turning off expenses explains why and links to balances.
- [ ] The shell updates immediately after a change.

**References:** [household contracts](../../../../packages/contracts/src/features/households/index.ts), [decision record: disabled modules](../../../decisions.md#disabled-modules)
