# 6.1 Add an assignee filter to the chore list

**Labels:** `backend`, `frontend` · **Epic:** [6 Chores](6.0-epic.md) · **Depends on:** [#47](https://github.com/diffiii/homesplit/issues/47)

**Goal:** A member can list just the chores assigned to them, for the chores page and the dashboard.

**Scope:** An optional `assignedToId` query parameter on `GET /chores`, with the contract, endpoint map, route doc, and an index.

**Acceptance criteria:**

- [ ] `assignedToId` returns only chores assigned to that user and combines with `includeCompleted`, keeping the contracted order and pagination.
- [ ] Any household party can be filtered on, so open chores of departed members can be found and reassigned. Another household's user IDs match nothing.
- [ ] Tests cover the filter with and without completed chores, departed assignees, and another household's IDs.
