# 4.2 Build the friends page

**Epic:** [4 Friends](4.0-epic.md) · **Depends on:** [2.1](../2-auth-account/2.1-sign-up-sign-in.md), [4.1](4.1-withdraw-friend-requests.md), [#31](https://github.com/diffiii/homesplit/issues/31), [#32](https://github.com/diffiii/homesplit/issues/32)

**Goal:** Users manage friends and friend requests in one place.

**Scope:** A friends page with the friend list, incoming and sent requests, and a send-by-email form.

**Acceptance criteria:**

- [ ] Friends are listed with name, avatar, and email, and can be removed after confirmation.
- [ ] Incoming requests can be accepted or declined, and sent requests withdrawn. Navigation shows the number of incoming requests.
- [ ] Sending a request reports 400 `USER_NOT_FOUND`, duplicates, crossed requests as [#31](https://github.com/diffiii/homesplit/issues/31) decides, and 429 `RATE_LIMITED` on the form.
