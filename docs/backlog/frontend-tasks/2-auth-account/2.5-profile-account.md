# 2.5 Build the profile and account settings

**Epic:** [2 Auth and account](2.0-epic.md) · **Depends on:** [2.1](2.1-sign-up-sign-in.md), [#30](https://github.com/diffiii/homesplit/issues/30)

**Goal:** Users manage their name, password, and theme in one place.

**Scope:** An account page using `PATCH /api/me` and Better Auth's `change-password`. Avatar upload is added to this page by [5.3.4](../5-expenses/5.3-attachments/5.3.4-avatar-ui.md), once file storage exists.

**Acceptance criteria:**

- [ ] The current profile comes from the session. Name changes are saved with `PATCH /api/me`, and the session and every cached `UserSummary` of the user are refreshed.
- [ ] The page shows the user's avatar, or initials without one.
- [ ] Changing the password asks for the current one and offers to sign out other sessions.
- [ ] The theme can be set to system, light, or dark, and is remembered on the device.
