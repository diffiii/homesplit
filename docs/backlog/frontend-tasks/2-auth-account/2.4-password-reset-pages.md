# 2.4 Build the password reset pages

**Epic:** [2 Auth and account](2.0-epic.md) · **Depends on:** [2.1](2.1-sign-up-sign-in.md), [2.3](2.3-password-reset-emails.md)

**Goal:** A user can recover access to their account from the sign-in screen.

**Scope:** A "forgot password" page and the `/reset-password` page.

**Acceptance criteria:**

- [ ] Sign-in links to a page that requests a reset email and always shows the same confirmation.
- [ ] `/reset-password` sets a new password with confirmation, explains an expired or used link with a way to request a new one, and then signs the user in or sends them to sign-in, depending on 2.3.

**References:** [2.3](2.3-password-reset-emails.md)
