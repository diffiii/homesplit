# 2.6 Build the profile and account settings

**Epic:** [2 Auth and account](2.0-epic.md) · **Depends on:** [2.1](2.1-sign-up-sign-in.md), [2.5](2.5-avatar-upload.md), [#30](https://github.com/diffiii/homesplit/issues/30)

**Goal:** Users manage their name, avatar, password, and theme in one place.

**Scope:** An account page using `PATCH /api/me`, the 2.5 avatar endpoints, and Better Auth's `change-password`.

**Acceptance criteria:**

- [ ] The current profile comes from the session. Name changes are saved with `PATCH /api/me`, and the session and every cached `UserSummary` of the user are refreshed.
- [ ] The avatar can be taken with the camera or picked from files, previewed, uploaded with progress, and removed. Initials are shown without one.
- [ ] Changing the password asks for the current one and offers to sign out other sessions.
- [ ] The theme can be set to system, light, or dark, and is remembered on the device.
