# 2.3 Send password reset emails

**Labels:** `backend`, `frontend` · **Epic:** [2 Auth and account](2.0-epic.md) · **Depends on:** [1.4](../1-foundation/1.4-backend-origin-links.md), [#59](https://github.com/diffiii/homesplit/issues/59)

**Goal:** A user who forgot their password gets an email with a link that lets them set a new one.

**Scope:** Configure Better Auth's `sendResetPassword` with the mail service and transports from [#28](https://github.com/diffiii/homesplit/issues/28) and [#59](https://github.com/diffiii/homesplit/issues/59), linking to the frontend's `/reset-password`.

**Acceptance criteria:**

- [ ] Requesting a reset for a registered email sends one email with a link to `/reset-password` that carries the token. The response is the same for unknown emails.
- [ ] Tokens expire after a configured time and work once. Resetting the password revokes the user's other sessions, and the decision is recorded.
- [ ] Reset requests are rate-limited per email and per IP address.
- [ ] Tests with the capturing transport cover sending, resetting, an expired token, a reused token, and an unknown email.

**References:** [Better Auth password reset](https://www.better-auth.com/docs/authentication/email-password#request-password-reset), [auth config](../../../../packages/backend/src/auth.ts)
