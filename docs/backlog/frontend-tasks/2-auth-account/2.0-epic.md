# Epic 2: Auth and account

**Backlog:** [Frontend backlog](../../frontend-backlog.md) · **Depends on:** [1 Foundation](../1-foundation/1.0-epic.md)

**Goal:** People create an account, verify their email, sign in, recover a forgotten password, and manage their profile and avatar.

**Tasks:**

- [2.1 Build sign-up, sign-in, and sign-out](2.1-sign-up-sign-in.md)
- [2.2 Build the email verification flow](2.2-email-verification.md)
- [2.3 Send password reset emails](2.3-password-reset-emails.md)
- [2.4 Build the password reset pages](2.4-password-reset-pages.md)
- [2.5 Add avatar upload](2.5-avatar-upload.md)
- [2.6 Build the profile and account settings](2.6-profile-account.md)

**Epic done when:**

- [ ] A Playwright test signs up, verifies the email from a captured message, signs out, resets the password, and signs in with the new one.
- [ ] A user changes their name and avatar, and other members see the new values; removing the avatar falls back to initials.
- [ ] A user who opens a protected link while signed out returns to it after signing in or signing up.
