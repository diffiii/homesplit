# 1.3 Move the allocation engine into the contracts

**Labels:** `backend`, `frontend` · **Epic:** [1 Foundation](1.0-epic.md) · **Depends on:** [#36](https://github.com/diffiii/homesplit/issues/36)

**Goal:** The expense form shows exactly the splits the backend will store, because both run the same code.

**Scope:** Move `allocate` with its validation and errors, and the money helpers it uses (`distributeProportionally`, `floorDiv`, and `toSafeInteger`), from `packages/backend/src` into `@homesplit/contracts`. The backend imports them from the contracts, including `toSafeInteger` for database reads.

**Acceptance criteria:**

- [ ] The moved code keeps its behavior and its unit tests, which now run with the contracts package in CI.
- [ ] The code has no Node-only dependencies and runs in the browser.
- [ ] The backend's allocation and money modules re-export or import from the contracts, with no second copy.
- [ ] [`docs/money.md`](../../../money.md) points to the new location.
