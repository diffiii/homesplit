# 1.8 Set up component and end-to-end tests

**Epic:** [1 Foundation](1.0-epic.md) · **Depends on:** [1.1](1.1-web-app-scaffold.md), [1.6](1.6-contract-mocks.md) · **Related:** [#23](https://github.com/diffiii/homesplit/issues/23)

**Goal:** Every task can prove its states, permissions, and accessibility with tests that run locally and in CI.

**Scope:** Vitest with Testing Library and axe for components, Playwright with axe for end-to-end flows, and CI jobs.

**Acceptance criteria:**

- [ ] `pnpm test:web` runs component tests against the MSW mocks, with an axe check helper.
- [ ] `pnpm e2e:web` runs Playwright against the app with mocks, at a 360 px mobile viewport and a desktop viewport, with axe checks.
- [ ] CI runs both on pull requests that touch `packages/web` or `packages/contracts`.
- [ ] A Playwright project can run against a real backend and database once [#23](https://github.com/diffiii/homesplit/issues/23) provides a seeded test setup.
