# Epic 1: Foundation

**Backlog:** [Frontend backlog](../../frontend-backlog.md)

**Goal:** Set up the web app and the shared plumbing every screen relies on: a typed API client built from the contracts, mocks, the app shell and UI kit, and a test workflow. Also land the few backend and contracts changes the frontend needs from the start.

**Tasks:**

- [1.1 Scaffold the web app](1.1-web-app-scaffold.md)
- [1.2 Add an endpoint map to the contracts](1.2-endpoint-map.md)
- [1.3 Move the allocation engine into the contracts](1.3-shared-allocation-engine.md)
- [1.4 Serve the backend behind the frontend origin and agree on email links](1.4-backend-origin-links.md)
- [1.5 Build the API layer](1.5-api-layer.md)
- [1.6 Mock the API from the contracts](1.6-contract-mocks.md)
- [1.7 Build the app shell and UI kit](1.7-app-shell-ui-kit.md)
- [1.8 Set up component and end-to-end tests](1.8-test-workflow.md)

**Epic done when:**

- [ ] `pnpm dev:web` starts the app against the mocks or a local backend, and CI lints, typechecks, builds, and tests `packages/web`.
- [ ] A sample screen loads a contract-typed list through the API layer, renders it in the shell in light and dark mode, and handles an `ApiError` and a Better Auth error.
- [ ] Better Auth sign-in works through the `/api/*` rewrite on a Vercel preview deployment.
