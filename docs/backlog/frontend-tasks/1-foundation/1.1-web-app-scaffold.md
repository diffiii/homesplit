# 1.1 Scaffold the web app

**Epic:** [1 Foundation](1.0-epic.md) · **Depends on:** none

**Goal:** `packages/web` exists as a Next.js app that builds, lints, and deploys like the rest of the monorepo.

**Scope:** A Next.js App Router app with TypeScript, Tailwind, and shadcn/ui; workspace scripts; CI jobs; environment config; the `/api/*` rewrite; and the PWA manifest.

**Acceptance criteria:**

- [ ] `packages/web` uses the current Next.js App Router with strict TypeScript, Tailwind, and `shadcn` initialized. Ultracite lints it with the root config.
- [ ] Root scripts include `dev:web` and `build:web`, and `pnpm dev` runs the backend and the web app together.
- [ ] The web app imports `@homesplit/contracts` without a manual build step in development and in Vercel builds (for example `transpilePackages`, or building the contracts in a pre-step).
- [ ] CI typechecks and builds `web` in the existing matrix.
- [ ] `next.config` rewrites `/api/:path*` to `API_URL`, a server-only variable. `.env.example` documents it, and the Vercel project is configured per environment (production API, staging API for previews).
- [ ] An app manifest, icons, and theme colors make the app installable on Android and iOS. No service worker is added.

**References:** [CI workflow](../../../../.github/workflows/ci.yml), [root package](../../../../package.json), [contracts package](../../../../packages/contracts/package.json)
