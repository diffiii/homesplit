# 1.7 Build the app shell and UI kit

**Epic:** [1 Foundation](1.0-epic.md) · **Depends on:** [1.1](1.1-web-app-scaffold.md)

**Goal:** Every feature screen is assembled from the same layout, states, form pieces, and formatting helpers.

**Scope:** Layouts, theme, shared components, form integration, and money and date helpers.

**Acceptance criteria:**

- [ ] Layouts exist for signed-out pages and for `/households/:householdId/...`, with bottom navigation on mobile and a sidebar on desktop. Signed-out users are redirected before the page renders.
- [ ] The shadcn theme defines colors, spacing, and typography for light and dark mode. Dark mode follows the system, can be overridden, and doesn't flash on load.
- [ ] Shared components cover page headers, empty states, error states with retry, skeletons, confirmation dialogs, and a dialog that becomes a bottom sheet on mobile.
- [ ] Forms use React Hook Form with the contract schemas, and server validation errors appear on the matching fields.
- [ ] Money helpers convert between typed input and integer minor units with the currency's exponent, without floating-point arithmetic, and format amounts with `Intl`. A currency picker lists supported currencies (browser ISO 4217 codes minus `UNSUPPORTED_CURRENCY_CODES`), PLN and recently used first.
- [ ] Date helpers treat `IsoDate` as a local calendar date and convert local date-times to and from UTC `IsoDateTime`.
- [ ] A user avatar component shows `imageUrl` or initials and can show a "left the household" badge.
