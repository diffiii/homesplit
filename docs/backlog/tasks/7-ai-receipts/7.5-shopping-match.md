# 7.5 Match receipts to the shopping list

**Epic:** [7 AI and receipts](7.0-epic.md) · **Depends on:** [7.4](7.4-receipt-expense.md), [6.2](../6-shopping/6.2-purchase-clear.md)

**Goal:** After a receipt is confirmed, the app suggests which unpurchased shopping-list items were bought, and the member confirms the suggestions.

**Scope:** An endpoint that returns match suggestions between receipt items and the household's unpurchased shopping items, and a bulk endpoint that marks the selected shopping items as purchased using the 6.2 purchase logic. Partial purchases (2 of 3 units bought) are out of scope, because purchase state is a single flag.

**Acceptance criteria:**

- [ ] Suggestions only contain unpurchased items from the receipt's household, and each one references the receipt item it matches. Matches the model returns for unknown or foreign item IDs are discarded.
- [ ] The bulk purchase sets the buyer to the receipt's payer and the purchase time to the confirmation time. It skips items that were purchased or deleted in the meantime and reports which ones were skipped.
- [ ] The endpoint requires the shopping and AI modules enabled. With AI disabled, the member can still pick items manually through the same bulk endpoint.
- [ ] Tests with the fake adapter cover exact and fuzzy matches (for example "Mleko 2% 1L" and "milk"), no matches, concurrent purchases, and another household's items.
