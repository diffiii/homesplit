# 7.2 Suggest expense categories

**Epic:** [7 AI and receipts](7.0-epic.md) · **Depends on:** [7.1](7.1-ai-provider.md), [4.1.1](../4-expenses/4.1-ledger/4.1.1-categories.md)

**Goal:** When a member enters an expense name, description, or photo, the app suggests one of the household's categories.

**Scope:** A suggestion endpoint that takes text and an optional attachment and returns a category suggestion. The endpoint doesn't modify any expense; the client fills the category field and the member can change it. Receipts in 7.4 reuse the same logic.

**Acceptance criteria:**

- [ ] The suggestion is always one of the requesting household's existing categories, or none. The model never creates categories, and an unknown or foreign category ID in the model output is discarded.
- [ ] The response contains the category ID and a confidence level, and the client contract documents when to prefill the field (for example only above a threshold).
- [ ] An attachment can only be used if it belongs to the requesting household.
- [ ] The endpoint requires membership and both the expenses and AI modules enabled.
- [ ] Tests with the fake adapter cover a matching category, no match, a hallucinated category ID, a household without categories, and another household's attachment.
