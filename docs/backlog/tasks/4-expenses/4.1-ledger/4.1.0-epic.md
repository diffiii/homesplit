# Sub-epic 4.1: Ledger

**Parent:** [Epic 4: Expenses](../4.0-epic.md)

**Goal:** Members create, edit, and delete expenses with categories, multiple payers, and server-calculated splits. Financial state always stays consistent.

**Tasks:**

- [4.1.1 Implement household expense categories](4.1.1-categories.md)
- [4.1.2 Implement the deterministic allocation engine](4.1.2-allocation-engine.md)
- [4.1.3 Add expense persistence and create/read endpoints](4.1.3-expense-persistence-create-read.md)
- [4.1.4 Implement expense update and delete with atomic financial replacement](4.1.4-expense-update-delete.md)

**Sub-epic done when:**

- [ ] The total of every stored expense equals the sum of its payer amounts and the sum of its splits.
- [ ] No request can attach another household's category, payer, or participant to an expense.
