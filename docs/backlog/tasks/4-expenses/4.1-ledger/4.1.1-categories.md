# 4.1.1 Implement household expense categories

**Epic:** [4.1 Ledger](4.1.0-epic.md) · **Depends on:** [2.2](../../2-households/2.2-feature-settings.md)

**Goal:** Each household has its own categories, which expenses can reference.

**Scope:** A category table with its migration and CRUD/list endpoints. Task 4.1.3 owns the deletion policy for categories referenced by expenses, together with its constraint, endpoint error mapping, and tests, once expense persistence exists.

**Acceptance criteria:**

- [ ] Categories store household, name, and a nullable icon. The list is unpaginated as contracted, and `null` patches clear the icon.
- [ ] Every operation enforces membership, the expenses module setting, and household ownership.
- [ ] A reusable reference check exists for 4.1.3 so that a category can't be attached to another household's expense.
- [ ] Optional: new households get a small set of default categories (for example Groceries, Utilities, Rent, Other).
