# 4.2.3 Generate deterministic settlement suggestions

**Epic:** [4.2 Settlements](4.2.0-epic.md) · **Depends on:** [4.2.2](4.2.2-balances.md)

**Goal:** Members get a list of transfers that, once recorded, clear all debt in each currency.

**Scope:** An unpaginated suggestions endpoint built on 4.2.2 balances using a documented, deterministic debtor/creditor matching algorithm. Suggestions are computed on the fly and never stored or executed.

**Acceptance criteria:**

- [ ] Each suggestion is a positive transfer, within one currency, from a debtor to a different creditor, and both parties are eligible to record payments.
- [ ] Applying all suggestions brings every balance in that currency to zero.
- [ ] Ordering and tie-breaking are stable, so repeated runs and reordered equivalent inputs produce identical output.
- [ ] Empty and all-zero balances and multiple currencies are handled. The documentation states the algorithm's complexity and doesn't promise a minimal number of transfers.
