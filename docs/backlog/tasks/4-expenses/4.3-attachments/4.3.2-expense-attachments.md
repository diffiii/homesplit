# 4.3.2 Attach files to expenses

**Epic:** [4.3 Attachments](4.3.0-epic.md) · **Depends on:** [4.3.1](4.3.1-file-storage.md), [4.1.4](../4.1-ledger/4.1.4-expense-update-delete.md)

**Goal:** An expense can have several attachments, and they are returned with the expense.

**Scope:** An expense-attachment link table with its migration, endpoints to attach, list, and detach files, and attachment summaries in the expense response. This task decides what happens to attachments when an expense is deleted.

**Acceptance criteria:**

- [ ] Only attachments from the expense's household can be linked, and the same attachment can't be linked to one expense twice.
- [ ] Expense get and list responses include attachment summaries (ID, MIME type, size) without download URLs, and a separate request returns a download link.
- [ ] Attaching and detaching files follows the expenses module setting: allowed while enabled, rejected while disabled. Reads are always allowed.
- [ ] The behavior when an expense is deleted (delete the files or keep them unlinked) is documented and tested.
- [ ] Tests cover attaching another household's file, detaching, deleting an expense with attachments, and the disabled module.
