# Epic 4: Expenses

**Backlog:** [Backend backlog](../../backend-backlog.md) · **Depends on:** [Epic 2](../2-households/2.0-epic.md)

**Goal:** Households record shared expenses, see who owes whom per currency, and record payments that settle debts.

**Sub-epics:**

- [4.1 Ledger](4.1-ledger/4.1.0-epic.md): categories, allocation engine, and expense CRUD
- [4.2 Settlements](4.2-settlements/4.2.0-epic.md): payments, balances, and suggestions
- [4.3 Attachments](4.3-attachments/4.3.0-epic.md): file storage and expense attachments

**Epic done when:**

- [ ] One end-to-end HTTP scenario creates a category, adds expenses using all five allocation methods, edits one expense's financial data, records payments, and confirms that balances and suggestions are correct in two currencies.
- [ ] A member who leaves keeps their history and outstanding balance, and the balance can still be settled.
- [ ] With the expenses module disabled, data stays readable and mutations are rejected.
