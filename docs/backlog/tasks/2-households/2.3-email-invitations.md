# 2.3 Send household invitations by email

**Epic:** [2 Households](2.0-epic.md) · **Depends on:** [2.1](2.1-membership-isolation.md)

**Goal:** Inviting someone to a household sends them an email with a link that lets them join after signing in or signing up.

**Scope:** Wire the organization plugin's `sendInvitationEmail` callback to a small mail service with a production transport and a capturing transport for dev and tests. Better Auth's invitation endpoints (invite, accept, reject, cancel, list) are reused rather than reimplemented.

**Acceptance criteria:**

- [ ] The email contains the household name, the inviter, and an accept link built from a configured frontend URL and the invitation ID. Provider credentials and the sender address come from environment config.
- [ ] Only the roles allowed by [1.1](../1-foundation/1.1-decisions-household-permissions-api.md) can invite, and an invitation can only be accepted by a signed-in user whose email matches it.
- [ ] Invitation expiry and re-invite behavior (cancelling earlier pending invitations) are configured explicitly, and a failed send doesn't leave a pending invitation that the inviter can't see or resend.
- [ ] Tests use the capturing transport to cover sending, accepting, expired and cancelled invitations, and a mismatched email.
