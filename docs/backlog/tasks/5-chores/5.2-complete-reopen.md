# 5.2 Implement complete and reopen actions

**Epic:** [5 Chores](5.0-epic.md) · **Depends on:** [5.1](5.1-chore-crud.md)

**Goal:** Completion is a state transition that records who completed the chore and when, not a writable boolean.

**Scope:** Complete and reopen action endpoints.

**Acceptance criteria:**

- [ ] New chores are open, with null completion metadata. Complete sets the completer and time atomically, and reopen clears both.
- [ ] A database check enforces the contracted open/completed invariant.
- [ ] The behavior for repeated actions (completing an already completed chore, for example) is defined.
- [ ] Tests cover authorization, repeated and concurrent transitions, and rollback.

**References:** [chore contracts](../../../../packages/contracts/src/features/chores/index.ts)
