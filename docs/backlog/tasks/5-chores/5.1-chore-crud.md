# 5.1 Implement chore storage and CRUD

**Epic:** [5 Chores](5.0-epic.md) · **Depends on:** [2.2](../2-households/2.2-feature-settings.md)

**Goal:** Members create, edit, list, and delete household chores.

**Scope:** A chore table with its migration and create/get/list/update/delete endpoints. Completion is handled in 5.2.

**Acceptance criteria:**

- [ ] A chore stores its writable fields, an optional assignee (validated as an eligible household member), an optional deadline, the creator from the session, and timestamps.
- [ ] `dueAt` is a nullable UTC datetime stored as `timestamptz`, and date-only values are rejected. On update, omitting it keeps the deadline and `null` clears it.
- [ ] Ordinary updates can't set completion fields.
- [ ] The list hides completed chores by default, decodes `includeCompleted` from the query string, and paginates deterministically.
- [ ] Tests cover nullable patches, cross-household assignees, authorization, the disabled module, and `dueAt` round trips.
