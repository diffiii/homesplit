# 3.3 Accept, decline, and remove friendships

**Epic:** [3 Users and friends](3.0-epic.md) · **Depends on:** [3.2](3.2-friend-requests.md)

**Goal:** Requests turn into friendships atomically, and either participant can end a friendship.

**Scope:** Accept and decline endpoints, a list of accepted friends, and friendship removal.

**Acceptance criteria:**

- [ ] Only the recipient can accept or decline. Accepting deletes the request and creates exactly one friendship in a single transaction.
- [ ] Constraints prevent duplicate or reversed friendship pairs, and only a participant can remove a friendship.
- [ ] The accepted-friends list is unpaginated and returns `FriendUser` projections.
- [ ] Tests cover unauthorized actions, concurrent acceptance, repeated actions, and rollback.
