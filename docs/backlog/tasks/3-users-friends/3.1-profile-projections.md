# 3.1 Implement profile updates and user projections

**Epic:** [3 Users and friends](3.0-epic.md) · **Depends on:** [1.2](../1-foundation/1.2-test-infrastructure.md), [1.3](../1-foundation/1.3-contract-validation-errors.md)

**Goal:** Users can edit their own profile, and every feature returns users through the same compact projections.

**Scope:** A current-user profile PATCH endpoint plus shared `UserSummary` and `FriendUser` mappers.

**Acceptance criteria:**

- [ ] Only the authenticated user's display name and avatar can be updated. Partial updates are supported, and `null` clears the avatar. Auth-owned fields and other accounts can't be targeted.
- [ ] The database `image` column maps to `imageUrl` everywhere, including for users who have no avatar.
- [ ] Email is included only in the authorized `FriendUser` contexts, not in every nested user summary.
- [ ] HTTP tests cover persistence, serialization, and empty-patch behavior.
