# 1.2 Add a PostgreSQL integration-test and migration workflow

**Epic:** [1 Foundation](1.0-epic.md) · **Depends on:** none

**Goal:** Feature tasks can test transactions, constraints, and authorization against a real database.

**Scope:** A repeatable backend test command, run locally and in CI, with an isolated PostgreSQL database, automatic migrations, fixture helpers, and cleanup. It must never touch the developer's normal database.

**Acceptance criteria:**

- [ ] Tests migrate an empty database and exercise the existing auth/organization schema and the status endpoint.
- [ ] Fixture helpers create signed-in users in two separate households, and unauthenticated clients, without sharing mutable state between tests.
- [ ] Test runs are isolated from each other, and a transaction-rollback test demonstrates this.
- [ ] The test command and the Drizzle migration generation/application workflow are documented, and the backend suite runs in [CI](../../../../.github/workflows/ci.yml).
