# Epic 1: Foundation

**Backlog:** [Backend backlog](../../backend-backlog.md)

**Goal:** Agree on the cross-cutting rules and build the shared plumbing that every feature relies on: decisions, a real-database test workflow, and contract-based request/response handling.

**Tasks:**

- [1.1 Decide household identity, permissions, lifecycle, and API conventions](1.1-decisions-household-permissions-api.md)
- [1.2 Add a PostgreSQL integration-test and migration workflow](1.2-test-infrastructure.md)
- [1.3 Integrate shared contracts with Nest validation and error handling](1.3-contract-validation-errors.md)

**Epic done when:**

- [ ] The decision record is merged, and feature tasks reference it instead of re-deciding policies.
- [ ] A root `pnpm test:backend` script runs backend integration tests against an isolated PostgreSQL database locally and in CI.
- [ ] A sample route under `/api` validates input with a shared schema and returns `ApiError` on failure.
