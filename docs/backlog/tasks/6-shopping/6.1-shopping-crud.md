# 6.1 Implement shopping item storage and CRUD

**Epic:** [6 Shopping](6.0-epic.md) · **Depends on:** [2.2](../2-households/2.2-feature-settings.md)

**Goal:** Members add, edit, list, and delete items on the household shopping list.

**Scope:** A shopping item table with its migration and create/get/list/update/delete endpoints. Purchasing is handled in 6.2.

**Acceptance criteria:**

- [ ] An item stores a name, a quantity (default 1, minimum 1), a nullable unit, the creator from the session, and an added timestamp.
- [ ] Ordinary updates can't set purchase fields.
- [ ] The list hides purchased items by default, decodes `includePurchased` from the query string, and paginates deterministically.
- [ ] Tests cover validation, authorization, the disabled module, and cross-household access.
